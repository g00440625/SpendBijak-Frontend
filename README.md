## Features

- 🔐 JWT authentication — login and register
- 📊 Financial dashboard — income, spent, remaining, savings, budget
- ➕ Log expenses by amount and category
- 🤔 **Should I Buy This?** — risk verdict with plain English explanation
- 🟢 Colour-coded results — green (safe), yellow (moderate), red (high risk)

---

## Tech Stack

`React 18` · `Vite` · `Tailwind CSS` · `Vercel`

---

## Run Locally

```bash
git clone https://github.com/YOUR_USERNAME/spendbijak-frontend.git
cd spendbijak-frontend
npm install
npm run dev
```

Open `http://localhost:5173`

> Requires the [SpendBijak Backend](https://github.com/g0040625/spendbijak) running locally or use the live API at `https://api.heleneathalia.ie`
